# دليل الألعاب

طبقة مرافقة عربية للأهالي فوق أدوات الرقابة الأبوية: **اعرف، اضبط، تحاور، اتفق.**
مقدَّم لجائزة نورة الملاحي للابتكار الاجتماعي التقني، المسار الثاني (تعرّض الأطفال لمحتوى لا يناسب أعمارهم، وضعف فاعلية أدوات الحماية الأبوية الحالية).

> **حالة البيانات (2026-10-10):** `data/titles/` فيها **20 عنوان حقيقي** بدون شارة «تجريبي». القيم من صفحات رسمية: App Store السعودي، Google Play (السعودية)، PlayStation (السعودية)، متجر Xbox (السعودية)، موقع ESRB، وموقع PEGI — لكل قيمة رابط واقتباس حرفي وتاريخ. التغطية: **التصنيف السعودي (GCAM/Gmedia/GAMR) 6 عناوين** كما تعرضه المتاجر السعودية، ESRB 6، PEGI 10، App Store 19، Google Play 17. **كل القيم بحالة «بحاجة مراجعة بشرية»**. الناقص «غير متوفر/ما لقيت» (موقع GCAM نفسه ما يرد). التفاصيل: `research/official-report.md` و`research/import-report.md`.

## المشكلة

ولدك يبي يحمّل لعبة. وش تعرف عنها؟ أدوات الرقابة الأبوية موجودة في كل جهاز تقريبًا، لكنها مبعثرة بين أكثر من تطبيق وإعداد، وأغلب أدلتها بالإنجليزي، وما تساعد الأسرة تفتح حوار عن اللعبة نفسها. والتصنيف العمري لحاله ما يبيّن أشياء مهمة مثل المحادثة مع الغرباء أو المشتريات داخل اللعبة.

## الحل والخطوات الأربع

حقلين فقط في البداية: **اسم اللعبة أو التطبيق** (بحث عربي/إنجليزي مع المرادفات: «ماين كرافت» = Minecraft، «ببجي» = PUBG Mobile) و**عمر الطفل** (3–17، لا يُخزن). بعدها:

1. **اعرف** — التصنيفات العمرية بالترتيب: الهيئة العامة لتنظيم الإعلام (GCAM) ← ESRB ← PEGI ← App Store ← Google Play. كل تصنيف برابط مصدره وتاريخ التحقق، أو «غير متوفر». مقارنة هادئة مع عمر الطفل. ثم **خمس نقاط انتباه ثابتة**: محادثة الغرباء، المشتريات وصناديق الحظ، نوع المحتوى، الإعلانات، مدة الجلسة والتوقف — كل نقطة بمصدر وشارة ثقة، أو «ما لقيت معلومة موثوقة».
2. **اضبط** — تبويبات لكل جهاز (iPhone/iPad، Android، PlayStation، Xbox، Switch، PC/Steam، وداخل اللعبة). خطوات مرقّمة للعناوين اللي راجعها إنسان، ورابط الدليل الرسمي فقط للباقي. كل خطوة فيها «سويتها» تنحفظ على الجهاز.
3. **تحاور** — 3 أسئلة مفتوحة حسب الفئة العمرية وأهم نقاط الانتباه، **واحد منها دائمًا عن الأصحاب**، مع «ليش هذا السؤال؟» و«إذا قال…». الاختيار deterministic مع زر «أسئلة غيرها».
4. **اتفق** — الأب يختار ← «أعطِ الجوال لطفلك» (اختيارات الأب مخفية تمامًا) ← الطفل يختار بواجهة أكبر ← «سلّم الجوال لأبوك» ← بنود متفق عليها أو **بند وسط** بقواعد ثابتة ← التزامات الأب ← **صفحة اتفاق A4** بتوقيعين وتاريخ مراجعة بعد أسبوعين (ميلادي وهجري) وQR. أقل من 7: الأب يقرر (أو يشرك الطفل بالصور). 13+: «أقترح بند».

و**ميثاق البيت** (`/charter`): كل الاتفاقات محفوظة على الجهاز فقط مع زر حذف.

## الميزات السعودية: عدسة الأسرة، وتتوقف وقت الصلاة؟

- **عدسة الأسرة** (قسم قابل للطي): القمار أو ما يشبهه، المحادثة الصوتية مع غرباء من الجنسين، السحر والشعوذة، اللبس والمظهر، الموسيقى — «موجود / غير موجود / ما لقيت» مع المصدر. بلغة وصفية بدون وعظ؛ الأسرة تقرر.
- **تتوقف وقت الصلاة؟**: «تتوقف بسهولة / لا تتوقف أثناء المباراة / ما لقيت» مع المصدر، ونصيحة عملية عامة (ضبط وقت التطبيقات قبل الأذان) بدون مواقيت مخترعة.

## المنهجية والمصادر ومستويات الثقة

- مصادر التصنيف: ESRB, PEGI, App Store, Google Play, GCAM فقط. الـschema ترفض أي تصنيف بدون `sourceUrl` و`verifiedAt`، و`npm run validate:data` يُفشل البناء.
- لا تحويل بين جهات التصنيف ولا تخمين: الناقص = «غير متوفر»، النقطة بلا مصدر = «ما لقيت».
- مستويات الثقة: **راجعها إنسان** / **آلية بمصادر** / **ما لقيت**.
- ممنوع كلمة «آمن/آمنة» في المنتج كله (tests تفحص الواجهة والبيانات والكود).
- التفاصيل: صفحة `/sources` و`docs/CONTENT_GUIDE.md`.

## الخصوصية (ما نجمعه وما لا نجمعه)

- **ما نجمع أبدًا:** حساب، اسم، عمر دقيق، اختيارات الطفل، نص حر من الطفل، IP، user agent، cookies تتبع، analytics طرف ثالث.
- **بعد موافقة صريحة فقط:** أحداث استخدام مجهولة مع الفئة العمرية (`under7` / `7to12` / `13plus`) ومعرّف جلسة عشوائي في `sessionStorage`.
- اختيارات الطفل تنحذف من الذاكرة فور توليد البنود (مختبرة).
- زر «امسح كل بياناتي من هذا الجهاز». التفاصيل: `/privacy` و`docs/PRIVACY.md`.

## التشغيل محليًا

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # Vitest (unit + component)
npm run test:e2e     # Playwright (Pixel 7 + Desktop) + axe
npm run lint && npm run typecheck && npm run validate:data && npm run build
```

المنتج يشتغل كامل **بدون أي متغيرات بيئة** (بدون LLM وبدون Supabase). المتغيرات الاختيارية في `.env.example`.
للعرض بالبطاقات التجريبية: `DALIL_DEMO=1 npm run dev` (أو `DALIL_DEMO=1 npm run build`).

## تعبئة البيانات المتحقق منها

```bash
npm run import:verified -- research/seed_titles_verified.json --dry   # تجربة بدون كتابة
npm run import:verified -- research/seed_titles_verified.json         # دمج + تحقق كامل
```

أي عنوان فيه رابط خارج النطاقات الرسمية، أو تصنيف بدون مصدر وتاريخ، أو كلمة ممنوعة، يُرفض ولا يُكتب.
`research/candidate_sources.json` فيه روابط **مرشّحة** من بحث عام مقيّد بالنطاقات الرسمية — غير متحقق منها ولا يستخدمها التطبيق.

### التحقق من المصادر الرسمية (App Store / Google Play)

```bash
npm run fetch:official            # يجلب الصفحات الرسمية ويحفظ مقتطفات حرفية في research/official_snapshot.json
npm run apply:official -- --dry   # يعرض التعديلات بدون كتابة
npm run apply:official            # يكتب القيم بحالة «بحاجة مراجعة بشرية» + research/official-report.md
```

المعرّفات في `research/official_sources.json`. أي صفحة ما تطابق اسم العنوان أو فشل جلبها ما يُكتب منها شي.

## الذكاء الاصطناعي (اختياري) وطريقة التحقق

يتفعّل فقط مع `ENABLE_AI_CARDS=true` و`ANTHROPIC_API_KEY`، وفقط لتوليد بطاقة «آلية بمصادر» لعنوان غير موجود. أربع مراحل في `src/lib/agent/`:

1. **identify** — العنوان الرسمي والمنصات والناشر (Zod).
2. **fetch** — صفحات من allowlist رسمية فقط (esrb.org, pegi.info, apple.com, play.google.com, gcam.gov.sa، ونطاق الناشر). لا محركات بحث ولا منتديات، ويُرفض أي redirect لخارجها.
3. **extract** — structured output؛ كل حقل يحمل `quote` حرفي + `sourceUrl`.
4. **verify** — (أ) كود يتأكد إن الاقتباس موجود حرفيًا في نص المصدر، (ب) نموذج ثاني يحكم «مدعوم/غير مدعوم». أي فشل ⇐ «ما لقيت». التصنيف يُقبل فقط لو الرقم مقتبس حرفيًا من صفحة الجهة المصنفة نفسها.

يوصل للنموذج **اسم العنوان فقط**. حد طلبات وحد يومي (`MAX_AI_CARDS_PER_DAY`)، والنتيجة تنحفظ في `data/review-queue/` لمراجعة بشرية. أسئلة الحوار والبنود الوسط **بدون** ذكاء اصطناعي.

## قياس الأثر والتقييم

- `/about/impact`: أعداد مجمّعة من الأحداث المجهولة، أو «لم يُقَس بعد».
- `npm run eval:agent`: يقارن الوكيل ببطاقات راجعها إنسان ويكتب `docs/EVALUATION.md`.
- **حتى الآن: لم يُقَس بعد.** ما فيه أرقام استخدام أو تقييم في هذه النسخة.

## حدود المنتج الحالية

- لا حجب، لا مراقبة، لا تحكم بجهاز الطفل.
- البيانات الحالية تجريبية ومعلّمة؛ العناوين الحقيقية تحتاج تعبئة ومراجعة بشرية.
- روابط الأدلة الرسمية للأجهزة بانتظار تحقق بشري (`verifiedAt: null`).
- مصدر تصنيفات GCAM يحتاج تحقق بشري من الصفحة الرسمية وطريقة الاستشهاد بها.

## خارطة الطريق

- تعبئة 30–50 عنوان شائع في السعودية ومراجعتها بشريًا.
- تجربة مع أهالي حقيقيين عبر رابط واتساب وقياس الاستخدام المجهول.
- تذكير مراجعة الاتفاق (إشعار محلي اختياري).
- مواقيت صلاة محلية اختيارية (تُحسب في المتصفح فقط).
- نسخة إنجليزية للمقيمين.
